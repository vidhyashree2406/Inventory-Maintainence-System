# Inventory Maintenance System

A simple **Inventory Maintenance System** developed to manage and maintain product stock efficiently. The system helps users maintain product details, monitor available stock, and manage inventory records using a database.

## Features

* 📦 Add new products
* 🔍 View product details
* ✏️ Update product information
* 🗑️ Delete products
* 📊 Manage available stock
* 🔎 Search products
* 💾 Store inventory records in a database
* 🧾 Maintain product and stock details

## Technologies Used

* **HTML**
* **CSS**
* **JavaScript**
* **PHP**
* **MySQL**
* **XAMPP**
* **phpMyAdmin**

## How It Works

The system allows users to maintain inventory records through a simple interface.

1. **Add Product** – Enter product details and store them in the database.
2. **View Products** – Display available products and their stock information.
3. **Update Product** – Modify existing product details or stock quantity.
4. **Delete Product** – Remove unwanted product records.
5. **Search Product** – Find products quickly using their details.

## Database

**MySQL** is used to store and manage inventory data. **phpMyAdmin** can be used to create and manage the database through XAMPP.

## CRUD Operations

The project implements the basic **CRUD operations**:

* **Create** – Add new inventory records
* **Read** – View existing product records
* **Update** – Modify product or stock details
* **Delete** – Remove inventory records

## How to Run

1. Install **XAMPP**.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Place the project folder inside the `htdocs` directory.
4. Create the required database using **phpMyAdmin**.
5. Configure the database connection in the PHP files.
6. Open the project in a browser through:

   ```text
   http://localhost/Inventory-Maintenance-System/
   ```
